# Helper runs

A helper run does one job in its own context and writes a result file. Each run starts at the role word named here, in the build folder. A run is done when you have read its result file and checked it against its brief.

- **Evidence run:** reading that step 2 sends out, such as tracing a flow through a repo. An `examiner`, briefed to use the `how` skill for what code does or the `why` skill for why. The brief names the repo's path, the question, the evidence that would settle it, the result file, and a length limit for it, such as 300 lines.
- **Diagram run:** draws one diagram into a file its brief names. A `writer`. The brief carries the figure's question and caption, its row and its level from the `diagrams` skill's table, its parts from the source, the page's key of marks, its SVG id prefix, the design plan's palette and typefaces, the widths and themes that step 4's Done when names, the 12 px label floor, and the paths of [figures.md](figures.md) and the `diagrams` skill's `drawing.md`.
