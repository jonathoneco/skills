# Clarify

The last message did not land. Explain it again, with a little context first.

1. **Tie it to the product:** what the product does, and what that means for the code.
2. **Draw the moving parts** as an inline diagram.
3. **Show it** with a code snippet, a real record, or whatever evidence fits the case.

Done when the new answer carries the context, the diagram, and the evidence.
