# Bottom line

The investigation is producing information, and the user wants it to head toward action. From here, what we would do decides what still needs looking into.

1. **Work each finding** through to what should be done about it. A fact worth chasing is one that changes what we would do.
2. **Sort the open questions** into the ones you can close yourself, by reading code or querying production, and the ones that are the user's call. Close yours as you go.
3. **Bring the user only theirs,** each phrased so a word answers it.
4. **Arrive at a short list of actions,** each with today's behavior, the change, and a checkable done condition. Leave nothing in it open.
5. **Say which calls you made yourself,** and why.

Done when every action has all three parts, and every open question is closed or is with the user.
